# Finance_Tracker
Your Personalize Finance Tracker to check how far are you from your Targets. This app helps you estimate savings, project timelines, and manage your income and expenses.


## Tech Stack
Streamlit — Rapid app deployment in Python

Supabase (PostgreSQL) — Scalable cloud database backend

Psycopg2 — Python PostgreSQL adapter

Python 3.11+

## Key Features

* Income Inputs (Pay per hour, Hours per day, Days worked)

* Expense Inputs (Grocery, Rent, Bills, Travel, etc.)

* Target Savings and Timeline Estimation

* Savings Mode Selection (High / Medium / Low / None)

* Automatic Warnings:

Target too ambitious

Timeline too short

Negative account balance

* Modern UI with custom CSS tweaks (smaller fonts, better metrics display)


## Future Improvements

* Add User Authentication via Supabase Auth

* Add Historical Savings Analytics (monthly graphs)

* Generate downloadable PDF Reports for users

* Email reminders if users are off-track

* Dashboard view for admins (monitor user savings trends)
